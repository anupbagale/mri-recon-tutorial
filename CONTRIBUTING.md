# Contributing and getting help

Thank you for your interest in this module. Contributions, corrections and questions are welcome.

## Reporting a problem

If a notebook does not run, a result looks wrong, or an explanation is unclear, please
[open an issue](https://github.com/anupbagale/mri-recon-tutorial/issues). Include:

- which notebook and section,
- what you expected and what happened (copy the error message if there is one),
- where you ran it (Google Colab, CPU or GPU, or your own computer with the package versions).

## Asking a question

Questions about the material, or about using it in your own teaching, are also welcome as
[issues](https://github.com/anupbagale/mri-recon-tutorial/issues). Please add the label `question`.

## Suggesting changes

1. Fork the repository and create a branch for your change.
2. Make the change. Keep notebooks free of outputs, except the files in `solutions/`.
3. Run the notebook you changed from top to bottom in a fresh Google Colab session.
4. Open a pull request that explains what you changed and why.

Small fixes such as typos can be made directly in the GitHub web editor.
